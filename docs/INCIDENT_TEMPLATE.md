# Incident記録雛形

発生時にdocs/evidence配下へ複製する。これはインシデント発生記録ではない。

## 概要と影響

発生日時、検知手段、影響するデータ・利用者・バージョン、既知と未確認を分けて記載する。

## 対応

封じ込め、復旧、証跡保全、秘密値の失効、担当者、実施コマンドと結果を残す。

## 再発防止と検収

原因、是正Task、回帰検証、残る制約、[Acceptance](acceptance/README.md) を接続する。
