# 通常run要約の親レビュー

親がR19の固定UC-CI接続を実装・レビュー・検証した。補助モデルへの委任は行っていない。

- 保存成果物を取った後にCIを再照会し、取得中の失効を現在利用へ反映する。
- 期待するmanifest・契約・baseline・対象・用途と、成果物集合・各artifactのdigestを照合する。
- 保存時のAssuranceと現在のCI利用を別々に表示する。取消しをHEALTHYの表示だけで成功にしない。
- 欠損や比較不能を0に補完しない。差分は保存された分数から計算する。
- 本文・CLI入口の出力失敗も終了2にする。内部例外を結果本文に転載しない。
- 実出力で長いJSON行を確認したため、Markdownを指標・理由・参照の表とUTC日時へ整えた。

最終の専用7テストは、JSON/Markdownの同一根拠、読取り途中の失効、取消し、本文改変・参照違い、
比較不能、通信/形式/出力障害、CLI入口の出力失敗を確認した。実DBでは失効済み通常runの終了1と
取消しrunの終了3を、製品コマンドから確認する。[証跡](../evidence/mvp-report-20260912/README.md)。

保存済みの固定fixture DBを別のローカル導線から読み、元の検証ファイルを変更しない。
確認用コンテナを回収して同じstate volumeを保持する。計画実行、変更採択、外部サービスの操作は行わない。
[全体監査](../mvp-completion-audit.md)のUC-LLM・監督入口・更新採択・修復確認などの残件は継続中である。
