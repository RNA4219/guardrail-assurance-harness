# 設計v0.1の見直し

要求v0.4・初期運用方針v1と設計初版を照合し、次の6件をv0.2へ修正した。要求IDと閾値・予算を増減していない。P1は誤った成功または利用目的の欠落につながる設計問題、P2は実装解釈の分岐を生む問題を示し、製品の脆弱性を実証した分類ではない。
